# BACK-82: React Flow read-only dependency-map pilot (supersedes BACK-81 for one bounded slice)

**Decision.** On 22 Nov 2026 the owner instructed, in chat, to adopt React Flow for Kawalys. [BACK-82](https://rahmaqanater.atlassian.net/browse/BACK-82) turns that into a bounded first integration. It **supersedes the "no React Flow for now" preference** in [DECISION-DIAGRAM-RENDERER.md](DECISION-DIAGRAM-RENDERER.md) (BACK-81, PR #56) for this one slice only. That record stays as written: it was accurate when it was made and BACK-81 stays Done.

**What this is not.** It is not a replacement of `DepGraph` or the V2 B+C `Canvas`, not a D3 platform decision, not an Architecture Explorer, not a production default, and not a deployment approval. The D3 modules that React Flow pulls in are allowed only inside this integration.

## What was built

- `@xyflow/react` **13.0.2**, exact-pinned in `app/package.json`; `app/package-lock.json` generated by `npm install --save-exact` (not hand-edited).
- A **read-only** renderer for the Project dependency map, behind a reversible flag: `?renderer=flow`. Any other value, or none, draws `DepGraph` exactly as before. There is no UI toggle and no route change.
- `app/src/view/flowModel.ts`: a pure, typed adapter from the already persona-scoped `mapFor()` output to nodes and edges. It copies ids, grid cells and edge certainty only. It never copies an edge's evidence basis, so no evidence id can reach the canvas.
- `app/src/components/flow/`: the lazy entry (`DepFlow.tsx`, with an error boundary that falls back to `DepGraph`), the canvas (`DepFlowCanvas.tsx`) and its scoped CSS. The library and its stylesheet load in a separate chunk, only when the flag is set.
- `DepGraph` and `DepTable` are untouched. The table stays under the map as the accessible, full-facts equivalent.

## Behaviour

| Area | Behaviour |
|---|---|
| Read-only | No node dragging, no connecting or reconnecting, no delete, no selection box, no zoom, no pan, no controls or minimap. |
| Selection | Same URL-based selection as DepGraph. Click or Enter selects; click again or Escape clears. |
| Keyboard | One tab stop per node (a real `<button>`). Edges, handles and node wrappers are not focusable, which removes the edge-by-edge path behind the 54-press finding in BACK-22. |
| Edges | Decorative and hidden from assistive tech; the table carries every link and its basis. Certainty by line style: solid declared, dashed provisional, dotted suspected. Never animated. |
| Language | Canvas always left to right (`dir="ltr"`). Node text follows the page language. The library's English strings (node and edge descriptions, edge labels) are replaced with EN/AR copy. |
| Layout | Fixed zoom 1, so every node stays a 44 px or larger target. A map wider than its panel scrolls sideways in a native wrapper, like `DepGraph`. Under 640 px the table still replaces the map. |
| Motion | No animated edges, no viewport transitions; the global reduced-motion rule also applies. |
| Failure | If the chunk cannot load or the renderer throws, `DepGraph` is drawn with the same data and a status note. |

## Known limits and open items

- **Attribution kept.** React Flow renders a "React Flow" link to reactflow.dev. It is left visible, as its authors ask of non-Pro users. Hiding it (`proOptions.hideAttribution`) is an owner decision. Its `aria-label` is English only and the library does not let it be changed.
- **`role="application"`.** The library sets it on its root and cannot be overridden by props. The canvas sets `role="presentation"` on that element once on mount and labels its own wrapper `role="group"`. A real screen reader has not checked this.
- **No zoom or pan.** Deliberate for a map of about ten nodes. A dense, zoomable surface is a separate decision and would need its own touch-target and keyboard work.
- **Manual screen reader and real devices** stay with BACK-32. **Native Arabic review** stays with BACK-31.

## Rollback

Remove the `?renderer=flow` parameter and the map is `DepGraph` again. To remove the integration, revert the PR: it touches `MapPanel.tsx`, `project.ts` (copy), `app/package*.json`, the new `flow/` folder, `flowModel.ts`, `rendererFlag.ts`, their tests and this note.
