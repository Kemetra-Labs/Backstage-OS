# BACK-23 owner decision, 22 Nov 2026: RepositoryAnalyzer = CodeGraph

**Decision.** The owner wrote "pick codegraph" on 22 Nov 2026. This record selects CodeGraph as the **RepositoryAnalyzer** engine and supersedes the "DEFER selection" recommendation for that one capability in [DECISION-PACKAGE.md](DECISION-PACKAGE.md) §1.

The decision covers the RepositoryAnalyzer port only. Under K-ARCH-01 the engine stays replaceable behind that port.

## Evidence the decision rests on

The scores come from the independent hold-out fixture v1 (36 files, 121 hand-written truth edges and 23 negatives), scored under the locked `kawalys.graph.v1` rules.

| | Frozen pass ([BACK-77](../holdout-v1-run/REPORT.md)) | After the D1/D4 normalizer fixes ([BACK-78](../holdout-v1-rescore/REPORT.md)) |
|---|---|---|
| CodeGraph TP / FN / FP (of 114) | 106 / 8 / 4 | 107 / 7 / 3 |
| Graphify TP / FN / FP | 89 / 25 / 3 | 96 / 18 / 3 |
| CodeGraph hard failures | 3 false observed, 6 schema errors | 2 false observed, 0 schema errors |
| Graphify hard failures | 2 false observed, 3 negatives hit, 1 unknown claimed | unchanged |

- **Both engines FAIL the strict v1 verdict.** Neither one passes cleanly.
- **CodeGraph asserts no relation that is absent from the source.** Its two remaining hard failures are granularity misses: calls inside an anonymous default export are attributed to the module.
- **Graphify's hard failures include two wrong relations:**
  - a shadowed parameter resolved to an import (N05);
  - a value reference read as a call (N23).
- **Both engines are deterministic** and give exact lines on every matched edge.

Graphify was re-scored again after the D2 fix in BACK-79. That re-score is informational only: it was made after this decision and does not affect it.

## Conditions attached to the decision

These conditions come from the G1 evidence. Each one must hold before CodeGraph processes anything other than synthetic fixtures.

1. **Licence sign-off: [BACK-80](https://rahmaqanater.atlassian.net/browse/BACK-80), blocking.** Still incomplete, for the platforms we would ship:
   - the native `codegraph-kernel.node` (73 Rust crates; build provenance not verified);
   - the vendored Node runtime;
   - 65 wasm grammars (36 in `tree-sitter-wasms` plus 29 vendored).
2. **Library API only.**
   - Run CodeGraph through `CodeGraph.init(root, { index: false })` and `indexAll()`, as in `back-21/cg_run.js`.
   - Never run the CLI `install`, `uninstall`, `init`, `index`, `serve --mcp`, `upgrade` or `daemon`. These can write agent configuration or git hooks, and some can enable telemetry ([BACK-21 preflight](../back-21/preflight.md)).
3. **No network.**
   - Set `DO_NOT_TRACK=1`, `CODEGRAPH_TELEMETRY=0`, `CODEGRAPH_NO_UPDATE_CHECK=1` and `CODEGRAPH_NO_DOWNLOAD=1`.
   - Use an egress block that binds Node (`NODE_USE_ENV_PROXY=1` was verified in BACK-77).
   - Actual traffic has not yet been captured; do so before any real source is indexed.
4. **Isolated checkout.** Index only an isolated copy of the authorized repository, outside any enclosing git repository (risk R3).
5. **Known gaps to handle in the normalizer or the UI:**
   - anonymous default exports;
   - Python `super()` calls;
   - decorators, which are emitted as `decorates` and currently dropped;
   - `external_refs` reported as 0;
   - unknowns that appear only as generic unresolved-call markers.

   Show these as Unknown, never as Healthy or complete.
6. **Scope.**
   - Evidence exists only for TS, TSX, JS and Python on synthetic fixtures.
   - Every other language, scale and full-map coverage (M03) are NOT RUN.
   - X02/X04 (identity, permissions, retention) stay open.

## What this decision does not change

- **DiagramRenderer stays deferred** ([DECISION-PACKAGE.md](DECISION-PACKAGE.md) §1). It is coupled to the React Flow / D3 dependency decision.
- **The other ports are not evaluated:** SourceConnector, ExplanationProvider and AgentRuntime.
- **No product code depends on CodeGraph yet.** Wiring it into `server/` or `app/` is a separate, approved slice that comes after BACK-80.
