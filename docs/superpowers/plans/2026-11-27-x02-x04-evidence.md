### Task 1: Origin / Sec-Fetch-Site guard (M1)
- Create `server/src/http/origin-check.ts` (middleware, registered in `create-app.ts` before routes) and `server/test/http/origin-check.spec.ts`.
- Rule: for methods other than GET/HEAD/OPTIONS: allow when `Sec-Fetch-Site` is `same-origin` or `none`; otherwise allow only when `Origin` is in `KAWALYS_ALLOWED_ORIGINS` (comma-separated exact origins, parsed by a pure `allowedOrigins(env)` that rejects malformed values naming the variable only). Default allowlist when unset: `http://127.0.0.1:4178`, `http://localhost:4178` (the Vite app origin) — never `*`. A request with neither header (server-to-server, curl, supertest) is allowed only when `NODE_ENV !== 'production'`; in production it is refused. Refusal = the standard 404 `not_found` envelope via the existing safe error path.
- Tests: cross-site Origin POST refused (404, nothing written); `Sec-Fetch-Site: cross-site` refused; same-origin allowed; allowlisted Origin allowed; GET unaffected; production + no headers refused; env parser cases. Keep every existing server test green (supertest sends no Origin → allowed outside production).
